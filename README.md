# 基于 SpringBoot + Vue 的药品销售系统 (Drug Sales System)

药品管理 · 在线购药 · 电子处方 · 库存预警 · 订单管理 · 供应商采购 · 物流跟踪 · 销售统计 · 多角色协同

本项目是一套面向药店零售场景的药品销售管理系统，采用前后端分离架构，覆盖管理员与普通用户两类角色。系统围绕“药品管理、库存管理、供应商管理、药品采购、订单管理、电子处方、在线支付、物流跟踪、销售统计、库存预警”等核心业务设计，支持用户在线注册登录、浏览药品、添加电子处方、购买药品、查看订单与缴费记录，管理员完成药品与药店管理、库存监控、供应商与采购管理、订单处理、公告发布、消息推送与多维度销售统计，适用于药店线上销售平台、医药零售管理系统、社区药房服务平台及药品进销存管理系统。

## 核心特性

- **多角色权限管理**：区分管理员与普通用户两类角色，实现不同权限隔离与功能访问控制。
- **药品全生命周期管理**：支持药品信息录入、分类管理、上架下架、批号与效期管理，保障药品信息准确合规。
- **库存预警机制**：实时监控药品库存数量，当库存低于设定阈值时自动触发预警，提示管理员及时补货。
- **电子处方管理**：用户可上传电子处方，管理员/药师对处方进行审核，处方药销售需关联有效处方，确保销售合规。
- **供应商与采购管理**：维护供应商信息，支持从供应商处进行药品采购，记录采购订单与入库信息，实现进销存一体化。
- **订单全流程管理**：覆盖下单、支付、发货、物流跟踪、收货与评价全流程，支持订单状态实时查询与缴费单下载。
- **物流信息管理**：记录订单物流状态与配送信息，用户可实时查看药品配送进度。
- **在线支付与缴费记录**：支持用户在线支付药品费用，自动生成缴费记录，便于用户查询与对账。
- **销售统计与排行**：提供日/月/年销售报表、热销药品排行、库存周转分析等多维度统计，辅助经营决策。
- **公告与消息通知**：管理员可发布系统公告，向用户推送订单状态变更、处方审核结果、库存补货提醒等重要消息。

## 功能模块概览

## 管理员端

管理员负责药店整体运营、药品与库存管理、供应链维护、订单处理与数据统计分析：

### 药品与库存管理

- **药品管理**：录入与维护药品信息，包括药品名称、编号、类型、规格、生产厂家、批准文号、功效、禁忌、单价、库存数量、批号、有效期、药品图片等，支持药品上架/下架操作。
- **药店管理**：管理药店基本信息，包括药店名称、地址、联系方式、营业时间等，支持多药店配置（可选）。
- **药店库存**：查看各药店/各药品的实时库存情况，支持按药品名称、类型、库存状态筛选。
- **库存统计**：统计当前库存总量、库存分布、库存周转率等数据，生成库存报表。
- **库存预警**：当药品库存低于设定阈值或临近有效期时，系统自动发出预警提示，管理员可及时处理补货或下架。

### 供应商与采购管理

- **供应商管理**：维护供应商信息，包括供应商名称、联系方式、资质文件、供应药品类型、信用等级等。
- **药品采购**：从供应商处发起药品采购，选择供应商与采购药品，填写采购数量与采购价格，生成采购订单并跟踪入库状态。

### 订单与处方管理

- **订单信息管理**：查看平台所有订单，包括订单编号、用户信息、药品明细、订单金额、支付状态、物流状态等，支持按时间、状态筛选。
- **订单详情**：查看单个订单的完整信息，包括药品清单、收货地址、支付记录、物流轨迹与操作日志。
- **订单评价**：查看用户对订单/药品的评价与评分，支持回复用户评价与处理售后问题。
- **缴费记录**：查看用户支付记录，包括支付金额、支付方式、支付时间与交易流水号。
- **物流信息管理**：录入与更新订单物流信息，包括快递公司、物流单号、配送状态，用户可实时查看物流进度。
- **电子处方管理**：查看用户上传的电子处方，进行处方审核（通过/驳回），处方药销售需关联有效处方，确保合规销售。

### 公告、消息与用户管理

- **公告管理**：发布系统公告，包括药品价格调整、活动通知、政策解读、维护通知与安全提示。
- **用户消息**：向指定用户或全体用户推送消息，包括订单状态变更、处方审核结果、库存补货提醒、活动信息等。
- **用户管理**：管理注册用户信息，包括账号状态、实名认证、角色分配，支持禁用异常账号与重置密码。
- **员工管理**：维护员工信息，包括姓名、工号、岗位、联系方式，分配员工操作权限。

### 数据统计

- **销售统计**：按日/周/月/年统计销售数据，包括销售额、订单量、客单价、支付方式分布等。
- **销售排行**：统计热销药品排行、滞销药品清单，支持按药品类型、时间段筛选，辅助采购与促销决策。

## 用户端

用户端面向普通注册用户，提供注册登录、药品浏览、处方上传、在线购药、订单管理与消息查看功能：

### 账户与个人信息

- **个人信息**：注册登录系统，维护昵称、手机号、头像、收货地址等个人信息。

### 药品购买与处方

- **药品购买**：浏览药品列表，按类型/名称/功效筛选，查看药品详情（功效、禁忌、售价、库存），加入购物车并提交订单。
- **添加电子处方**：上传电子处方图片或填写处方信息，提交后等待管理员/药师审核，审核通过后可购买对应处方药。

### 订单与支付管理

- **我的订单**：查看个人所有订单，包括待支付、待发货、配送中、已完成等状态，支持查看详情与下载缴费单。
- **缴费记录**：查看个人支付记录，包括支付金额、支付方式、支付时间与订单关联信息。
- **订单评价**：对已完成的订单/药品进行评分与文字评价，分享购药体验。

### 消息通知

- **我的消息**：接收订单状态变更、处方审核结果、发货通知、系统公告等消息，支持标记已读与删除。
